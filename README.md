# 日本語 Master

Интерактивное веб-приложение для изучения японского языка: две азбуки,
иероглифы, словарь, грамматика, диалоги и тесты. Прогресс сохраняется
прямо в браузере, никакой регистрации не нужно.

## Как запустить

Нужен установленный [Node.js](https://nodejs.org) (версия 18 или новее).

```bash
npm install     # поставить зависимости (делается один раз)
npm run dev     # запустить сайт для разработки
```

После запуска открой в браузере адрес, который покажет консоль —
обычно это `http://localhost:5173`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запускает сайт на своём компьютере с горячей перезагрузкой |
| `npm run build` | Собирает готовую версию в папку `dist` |
| `npm run preview` | Показывает собранную версию, как она будет в интернете |
| `npm run lint` | Проверяет код на ошибки |

Страницы грузятся по мере надобности, поэтому первый экран открывается
быстро, а разделы подтягиваются при переходе.

## Что внутри

### Разделы

- **Хирагана** — 71 знак: 46 основных и 25 с дакутэн/хандакутэн
- **Катакана** — 71 знак, с примерами заимствованных слов
- **Кандзи** — 131 иероглиф уровня JLPT N5 с чтениями и примерами
- **Прописи** — настоящий порядок черт (данные KanjiVG) для всех 131
  кандзи: смотри анимацию письма и обводи от руки на холсте
- **Собери предложение** — игра: расставь слова-плитки в правильном
  порядке, 27 предложений трёх уровней сложности
- **Словарь** — 244 слова уровня N5 плюс около 900 слов и терминов из
  учебника «Минна но Нихонго I», все 25 уроков целиком
- **Грамматика** — теория и задания по 30 урокам учебника, с фуриганой
  над кандзи в примерах
- **Диалоги** — готовые разговоры на бытовые темы с озвучкой и разбором
  по фразам
- **Собери предложение** — отдельно от списка выше, см. ниже
- **Карта Японии** — префектуры и достопримечательности
- **Учебник** — просмотр PDF прямо в приложении (см.
  [«Учебник»](#учебник) ниже)
- **Дорожная карта** — весь путь до уровня N5 по шагам
- **Повторение** — карточки, у которых подошёл срок по интервальному
  повторению (SRS)
- **Тесты** — четыре режима проверки себя, включая смешанный
- **Экзамен N5** — пробный JLPT: три раздела, свой таймер на вопрос,
  разбор ошибок только в конце, как на настоящем экзамене
- **Прогресс** — недельная цель по новым словам, календарь активности,
  история тестов
- **Статистика** — точность, календарь занятий, достижения
- **Настройки** — тема оформления, голос озвучки (выбор, скорость,
  громкость, тон), магазин очков и мелкие переключатели

Прогресс по каждому разделу виден прямо на главной, на его карточке.
Когда открывается новое достижение, оно прилетает уведомлением в углу.

### Карточки

Главный элемент приложения — карточка с 3D-переворотом. Спереди японский
символ, сзади чтение, перевод и пример использования. После переворота
появляются три кнопки: «Знаю», «Повторить» и «Сложно» — по ним приложение
понимает, что ты уже выучил.

Есть и полноэкранный режим флеш-карточек: одна большая карточка за раз,
листается стрелками, пробел переворачивает, Esc выходит.

### Выбор карточек галочками

У каждой карточки в левом верхнем углу есть галочка. Снятая галочка
приглушает карточку — такая карточка не попадёт ни в тренировку
флеш-карточками, ни в тесты.

Отмечать можно не по одной:

- **галочка у названия ряда** отмечает или снимает сразу весь ряд
  («Ряд К», «Гласные», «Числа», «Глаголы» и так далее)
- **«Отметить весь блок»** — весь блок основных или весь блок дакутэн
- **«Отметить всё» / «Снять всё»** в шапке раздела — весь раздел целиком

Вверху раздела видно, сколько карточек сейчас отмечено. В настройках теста
есть переключатель «Только отмеченные карточки» — он включён по умолчанию,
но его можно снять и тогда в тест пойдут все карточки раздела.

Выбор сохраняется вместе с прогрессом, так что после перезагрузки
страницы отмеченное останется.

### Тесты

1. **Ввод чтения с клавиатуры** — показан знак, печатаешь его чтение
   латиницей (например `ji`) и жмёшь Enter
2. **Выбор перевода** — показан символ, надо выбрать один из четырёх
   вариантов; отвечать можно цифрами 1–4 на клавиатуре
3. **На слух** — звучит слово, надо выбрать нужный символ
4. **Смешанный** — режимы 1-3 чередуются вопрос за вопросом, в одном тесте

Можно настроить раздел, количество вопросов (10–50) и таймер на вопрос.

В разделах «Хирагана» и «Катакана» карточки поделены на два блока:
**основные знаки** и **дакутэн с хандакутэн**. У каждого блока свой счётчик
выученного и своя кнопка тренировки. Кнопками сверху можно оставить на
экране только один блок.

Для хираганы и катаканы в тестах есть такой же выбор: **все знаки**, **только
основные** (46 штук) или **только дакутэн** (озвончённые が, ざ, だ, ば, ぱ).
Если выбрать «только основные», озвончённые в тесте не попадутся.

За правильный ответ дают 10 очков. За серию правильных подряд включается
множитель: с трёх подряд очки идут ×2, с пяти — ×3. Ошибся — серия
обнуляется. В конце показывается результат и разбор всех ошибок.

Быстрее всего начать с главной страницы: там есть четыре кнопки, которые
сразу запускают тренировку ввода, минуя настройки.

## Как устроен код

```
src/
├── components/
│   ├── cards/     карточка с переворотом, сетка карточек, флеш-режим
│   ├── quiz/      настройка теста, сам тест, экран результатов
│   ├── grammar/   теория и упражнения по урокам
│   ├── layout/    меню и общая обёртка страниц
│   └── ui/        кнопки, прогресс-бары, модалка, фон с сакурой, фуригана
├── pages/         по файлу на каждую страницу
├── data/          все символы, слова, диалоги, грамматика
├── store/         прогресс и настройки (Zustand + localStorage)
├── hooks/         подсчёт статистики
├── utils/         перемешивание, звуки, озвучка, фуригана, адаптивный
│                  уровень, хранение файла учебника в браузере
└── styles/        глобальные стили и тема Tailwind
```

### Технологии

- **Vite** — сборка и dev-сервер
- **React + TypeScript** — интерфейс со строгой типизацией (никаких `any`)
- **TailwindCSS 4** — стили; все цвета лежат в `src/styles/globals.css`
  переменными и подменяются атрибутом `data-theme` на `<html>`
- **Framer Motion** — все анимации: переворот карточек, переходы страниц, лепестки
- **React Router** — переходы между разделами
- **Zustand** — прогресс, очки и история тестов, всё сохраняется в localStorage

### Звук

Звуки не лежат файлами — они генерируются в браузере через Web Audio API
(`src/utils/sound.ts`). Озвучка японского берётся из встроенного синтезатора
речи браузера (`src/utils/speech.ts`). В настройках можно выбрать конкретный
голос из тех, что видит браузер, и подстроить скорость, громкость и тон —
подойдёт, если доступно несколько голосов и хочется найти наиболее
естественный. Если японского голоса в системе нет,
режим «на слух» просто отключается сам.

## Грамматика

30 уроков (25 по учебнику «Минна но Нихонго I» плюс 5 дополнительных),
у каждого две вкладки:

- **Теория** — грамматические пункты простыми словами: формула
  конструкции, объяснение и примеры предложений с озвучкой (кнопка рядом
  с каждым примером). Кандзи в примерах подписаны фуриганой — чтением
  маленькой каной сверху, как в настоящих учебниках
- **Задания** — упражнения на пройденную грамматику: выбор варианта
  или ввод текста. После ответа сразу видно, верно или нет, и почему —
  с подсказкой. Внизу — счётчик правильных ответов и кнопка «Начать заново»

От простого (уроки 1-5: は/です, これ/それ/あれ, ここ/そこ/あそこ, время
и вежливые глаголы, глаголы движения へ/で/と) через て-форму, счётчики
и сравнение (6-18) до сложного: определения-предложений вместо «который»,
とき, たら/ても и вежливых глаголов あげます/もらいます/くれます (19-25).
Уроки 26-30 — дополнительные темы продвинутого уровня: причина (から/ので/のに),
вежливые просьбы, опыт и умение, долженствование и запрет, предположения
(かもしれません/ようだ/らしい).

## Дорожная карта

Отдельная страница показывает весь путь до N5 девятью шагами: сначала
основные хираганы, потом дакутэн, потом катакана, первые кандзи, первые
слова и так далее. Шаг считается пройденным, когда выучено 90% его
карточек. Пройденные отмечены галочкой, текущий подсвечен и имеет кнопку
«Идти», остальные закрыты замком.

Текущий шаг дублируется карточкой на главной, чтобы всегда было понятно,
чем заняться дальше.

## Что ещё показывает статистика

- **Точность ответов** — сколько всего было попыток, сколько верных и
  какой процент
- **Календарь активности** — квадратик на каждый день за последние полгода,
  закрашивается в дни занятий
- **Что стоит подтянуть** — двенадцать карточек, в которых ты чаще всего
  ошибаешься, с процентом правильных ответов

## Темы оформления

На странице «Настройки» можно переключить внешний вид. Смена темы
перекрашивает приложение целиком, потому что все цвета заданы
переменными в `src/styles/globals.css`.

| Тема | Какая она |
| --- | --- |
| Индиго | Почти чёрный фон, сине-фиолетовый акцент. Стоит по умолчанию |
| Красная | То же самое, но акцент красный |
| Космос | Фиолетовый градиент, стеклянные карточки, свечение, радужные заголовки |
| Светлая | Белый фон и чёрный текст, как в бумажном учебнике |
| Море | Тёмно-синий фон с бирюзовым акцентом |

Там же переключаются лепестки сакуры на фоне, звуки и анимации переходов.
Лепестки всегда розовые, на цвет темы они не завязаны.

Чтобы добавить свою тему: допиши блок `:root[data-theme='...']` в
`globals.css` и строку в `src/data/themes.ts`. Больше ничего менять не надо.

## Где хранится прогресс

В localStorage браузера под ключом `nihongo-master-progress`. Если открыть
приложение в другом браузере или в режиме инкогнито — прогресс будет пустой.
Сбросить всё можно кнопкой внизу страницы «Статистика».

## Учебник

Отдельная страница показывает PDF учебника прямо в браузере — без
парсинга и без загрузки куда-либо. Файл не входит в проект (это чужой
коммерческий материал, который нельзя раздавать всем посетителям
публичного сайта):

- если файл `public/textbook.pdf` лежит на диске (личная сборка
  разработчика, в `.gitignore`) — он подхватывается автоматически;
- иначе приложение один раз попросит выбрать свой PDF с диска. Файл
  сохраняется только в этом браузере (IndexedDB, `src/utils/localFileStore.ts`)
  и никуда не отправляется.

## Если захочешь добавить тесты кода

Vitest не установлен, чтобы не тянуть лишнее. Добавляется одной командой:

```bash
npm install -D vitest
```

Потом допиши в `package.json` в раздел `scripts` строку `"test": "vitest"`.
